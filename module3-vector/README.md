# Module 3 - Vector search & RAG with InterSystems IRIS

Follow **Workshop Guide.docx** (Hebrew: **Workshop Guide - Hebrew.docx**). Everything in this module runs in the
day's workshop container (`aiworkshop-iris`) in namespace **VECTOR**. The OpenAI key for the exercises is given out
in the room.

Open **this folder** (`module3-vector`) in VS Code: its `.vscode` settings connect the ObjectScript extension to
IRIS (namespace VECTOR), and saving a `.cls` file compiles it.

| Folder / file | What it is |
|---|---|
| `exercises/` | the files you work on: `Ex1.cls` ... `Ex4.cls` and the Exercise 4 notebook (the SQL is in the guide) |
| `solutions/` | the completed versions (same class names - paste if you fall behind) |
| `data/` | the fictional handbook PDFs the exercises search |
